# 💅 Ma'art Nails
### Site profissional para apresentação de serviços de manicure, cuidados com unhas e agendamento de atendimento

![React](https://img.shields.io/badge/React-18.2.0-61DAFB?logo=react&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-5.4-7C4DFF?logo=vite&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)

Projeto desenvolvido para a apresentação profissional da **Ma'art Nails**, com o objetivo de divulgar serviços de manicure, mostrar o espaço de atendimento, apresentar trabalhos realizados e facilitar o contato com clientes.

A aplicação foi desenvolvida utilizando **React + Vite**, com uma interface moderna, responsiva e seguindo uma identidade visual elegante voltada ao segmento de beleza.

# ⚙️ Como Rodar o Projeto

## Pré-requisitos

- Node.js instalado
- npm ou yarn

---

## Instalação

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/site-maart-nails.git
```

Entre na pasta:

```bash
cd site-maart-nails
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

Acesse:

```
http://localhost:5173
```
